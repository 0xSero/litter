1. Home screen

The launch black screen is most likely AlphaAnimatedImageView decoding all 165 frames of home_cat_entrance.webp on the main thread before the first frame. The cat also mounts at every cold start, because "no snapshot yet" is treated as "no sessions". Measure with signposts first, then fix.

  • Decode the cat off the main thread; show a still image first.
  • Show the cat only when sessions are known to be empty.
  • Persist the last session list in the Rust store and render it at launch with an "Updating…" pill.
  • Give the launch screen the theme background and logo.

  • Replace the zoomable home layout with a plain list.

6. All screens (round 2)

Same design system on every screen: SF Pro, 17pt body, 20pt margins, ~60pt rows, grouped inset lists, plain-glyph nav buttons. The approved round-1 home and conversation mockups were the style reference for each image.

6.1 Home with 10 servers — three options

Recommendation: A. Sessions stay the main content no matter how many servers are connected, and one tap filters to a server. C is better for people who think in servers first, but it grows with every server added.

7. Litter identity — three directions

Round 2 read too much like ChatGPT. These keep the calm base (17pt SF Pro, 20pt margins, generous spacing) and the conversation features worth preserving (widgets, subagent cards, turn metrics, context ring, Latest), and add a Litter identity from assets the app already has: kittylitter mint #00FF9C, the Kitty Litter theme amber #F59E0B, the cat colors, and Berkeley Mono.

Cleanliness rules for all three: one accent color per theme; separate things by tone rather than borders; one left edge for text, cards and rows; no text under 13pt; metadata in one style only; icons from one SF Symbols weight.

Fix before building: in B the user message came out in monospace; it should stay SF Pro, with only the "you · 9:41" label in mono.

9. Round 4 — quiet

Rules: no icons in lists (icons only for actions: back, settings, compose, +, mic, send); no status lights for healthy states; problems appear as one colored mono word ("needs approval", "offline", "reconnecting"); no accent color, white send button; no cat avatar or context ring in conversations; tool and subagent activity as plain mono lines; turn metrics hidden by default (tap a turn to see them). Mono metadata remains the identity.
