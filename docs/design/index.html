1. Rules

  • Content is text. Lists have no icons, avatars, chips, badges or status dots.
  • Icons only for actions: back, close, settings, compose, +, mic/send/stop, "…".
  • Healthy states show nothing. Problems show one colored mono word: needs approval, reconnecting, offline.
  • No accent color. The one primary button is white on dark, black on light.
  • No borders, hairlines or shadows. Spacing separates things. Raised surfaces only for code, widgets, sheets, menus and the composer.
  • Two text styles carry almost everything: SF Pro 17 for content, mono 13 lowercase gray for metadata (up to three items, joined by " · ").
  • Mono lowercase section labels group lists: now / today / yesterday on home, general / this iphone / advanced in settings, connected / needs attention in servers.
  • User messages: text with a 2pt left rule and a small mono "you · 9:34" label. A faint 1pt line separates whole turns.
  • Monospace appears only in metadata, code, commands, paths and the terminal. Never in reading text.
  • The composer has one right-hand button that changes role: mic when empty, send when typing, stop while the agent runs.
  • Generative widgets are the one rich element in a conversation. They keep their own rendering.
